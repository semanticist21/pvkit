# haurwitz — Haurwitz clear-sky GHI

Clear-sky global horizontal irradiance from the apparent solar zenith alone. Best monthly
error among zenith-only models in Reno et al. (2012).

## Principle

`GHI = 1098 · cos z · exp(−0.059 / cos z)` W/m², with `z` the refraction-corrected zenith.

Guard: `GHI = 0` when `cos z ≤ 0` (sun at/below horizon) and for a NaN zenith — same as
pvlib, which only evaluates the formula where `cos z > 0`. No input validation: every
finite zenith is meaningful.

## Reference

- **Spec:** B. Haurwitz, "Insolation in relation to cloudiness and cloud density",
  *J. Meteorology* 2:154–166, 1945,
  doi:10.1175/1520-0469(1945)002<0154:IIRTCA>2.0.CO;2; coefficients as presented in
  M. Reno, C. Hansen, J. Stein, "Global horizontal irradiance clear sky models:
  implementation and analysis", SAND2012-2389, 2012, https://doi.org/10.2172/1039404.
- **Reference implementation:** `pvlib.clearsky.haurwitz` @ pvlib 0.16.1.
- **Fixtures:** `haurwitz-fixtures.json` (73 cases: zenith 0/30/60/80, negative, horizon
  89–90.001°, below horizon to 180°, 40 random 0–100°, 20 random 85–90°), generated by
  `scripts/fixtures/clearsky-haurwitz.py`. No worked example in the paper.
- **Tolerance:** `1e-10` W/m² absolute. Observed max error vs pvlib on V8: 1.1e-13 W/m²
  (≈1 ULP at ~1000 W/m²). Same closed form in float64; margin covers cross-engine `Math.*`.
