# total-irradiance — plane-of-array irradiance from DNI/GHI/DHI

## Principle

`poaSkyDiffuse` from the selected sky model (`isotropic` default, `klucher`, `haydavies`,
`reindl`, `perez`), `poaGroundDiffuse` from `groundDiffuse` (albedo default 0.25),
`aoi` from `aoi`, combined by `poaComponents`. Exactly pvlib's composition, so all guards
(sun below horizon, zero irradiance) are those of the component methods.

Differences from pvlib by design: `perez` requires `airmassRelative` (pvlib would compute
Kasten–Young air mass itself, but modules may not import `atmosphere`; pass
`relativeAirmass(...)` output, NaN below the horizon); `surface_type`, `perez-driesse`
and `diffuse_components` are not supported. `haydavies`/`reindl`/`perez` require `dniExtra`
(typed per model; missing → RangeError, as pvlib's ValueError). Unknown model → RangeError.

## Reference

- **Spec:** see the component methods' `.md` files.
- **Reference implementation:** `pvlib.irradiance.get_total_irradiance(..., dni_extra,
  airmass, albedo, surface_type=None, model, model_perez, diffuse_components=False)`
  @ pvlib 0.16.1.
- **Fixtures:** `total-irradiance-fixtures.json` (16 edge scenarios × 5 models + 30 random
  scenarios with rotating model / Perez coefficient set), generated by
  `scripts/fixtures/irradiance-total-irradiance.py`.
- **Tolerance:** `1e-12` relative to `max(1, |expected|)` W/m². Observed max error: 3.0e-15 (relative; non-finite outcomes match exactly).
