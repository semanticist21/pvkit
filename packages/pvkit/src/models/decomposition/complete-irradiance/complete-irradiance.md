# complete-irradiance — GHI/DHI/DNI closure

## Principle

`GHI = DHI + DNI · cos z`; given two components, solve for the third.

- Missing DNI: `DNI = (GHI − DHI) / cos z` with pvlib `irradiance.dni` guards — negative →
  NaN; zenith ≥ 88° and DNI ≠ 0 → NaN; with `dniClearsky`, zenith in [80°, 88°) and
  DNI > 1.1·dniClearsky → clipped to 1.1·dniClearsky (pvlib `clearsky_tolerance=1.1`).
- Missing GHI or DHI: plain closure, no guards (negative DHI passes through, as pvlib).
- Anything but exactly one omitted component → `RangeError` (pvlib raises `ValueError`).

## Reference

- **Spec:** the closure identity (e.g. Duffie & Beckman, *Solar Engineering of Thermal
  Processes*, 4th ed., Wiley 2013, §2.8); DNI guards per pvlib `irradiance.dni`.
- **Reference implementation:** `pvlib.irradiance.complete_irradiance` @ pvlib 0.16.1
  (one-row Series inputs; `dni_clear` only where given).
- **Fixtures:** `complete-irradiance-fixtures.json` (57 cases: negative DNI, 88° zero/non-zero
  DNI, clear-sky clipping inside/outside 80–88°, below horizon; 45 random over all three
  directions), generated by `scripts/fixtures/decomposition-complete-irradiance.py`. NaN is
  stored as `null`.
- **Tolerance:** `1e-9` W/m². Observed max error 0 — same three-op formulas.
