# erbs — Erbs diffuse-fraction model

## Principle

`kt` = clearness index with `I0` = Spencer extraterrestrial irradiance (solar constant
1366.1 W/m²) or the caller's `dniExtra`, clipped to [0, 1]. Diffuse fraction (Erbs Eq. 1):

- `kt ≤ 0.22`: `df = 1 − 0.09 kt`
- `0.22 < kt ≤ 0.8`: `df = 0.9511 − 0.1604 kt + 4.388 kt² − 16.638 kt³ + 12.336 kt⁴`
- `kt > 0.8`: `df = 0.165`

`DHI = df · GHI`, `DNI = (GHI − DHI) / cos z`. Guard (pvlib): zenith > `maxZenith` (87°),
GHI < 0 or DNI < 0 → DNI = 0, DHI = GHI, keeping the closure. `RangeError` when neither
`timeMs` nor `dniExtra` is given or `timeMs` is non-finite.

## Reference

- **Spec:** D. G. Erbs, S. A. Klein, J. A. Duffie, "Estimation of the diffuse radiation
  fraction for hourly, daily and monthly-average global radiation", *Solar Energy*
  28(4):293–302, 1982, doi:10.1016/0038-092X(82)90302-4.
- **Reference implementation:** `pvlib.irradiance.erbs` @ pvlib 0.16.1, `min_cos_zenith`
  and `max_zenith` passed explicitly; `dniExtra` cases pass a day-of-year and record
  `get_extra_radiation(doy)` as the input.
- **Fixtures:** `erbs-fixtures.json` (94 cases: each kt branch, kt clipped, negative GHI,
  zenith 86.9/87.1/89.5/120°, doy 1/366, leap day, non-default guards; 50 random, 15 zenith
  80–92°, 15 `dniExtra`), generated by `scripts/fixtures/decomposition-erbs.py`. Also
  asserted: Eq. 1 at kt = 0.5 gives df = 0.65915.
- **Tolerance:** `1e-9` (W/m²; kt dimensionless). Observed max error 0 vs pvlib.
