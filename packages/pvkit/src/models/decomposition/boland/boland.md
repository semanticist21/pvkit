# boland — Boland logistic diffuse-fraction model

## Principle

`kt` as in erbs (Spencer `I0`, solar constant 1366.1 W/m², or caller `dniExtra`; clipped to
[0, 1]). Diffuse fraction `df = 1 / (1 + exp(a (kt − b)))`; defaults `a = 8.645`,
`b = 0.613` (15-min fit; 1-hour fit `a = 7.997`, `b = 0.586`). `DHI = df · GHI`,
`DNI = (GHI − DHI) / cos z`, with the same guard as erbs (zenith > `maxZenith`, GHI < 0 or
DNI < 0 → DNI 0, DHI = GHI). Shares erbs' kt and split helpers.

## Reference

- **Spec:** J. Boland, L. Scott, M. Luther, "Modelling the diffuse fraction of global solar
  radiation on a horizontal surface", *Environmetrics* 12(2):103–116, 2001,
  doi:10.1002/1099-095X(200103)12:2<103::AID-ENV447>3.0.CO;2-2; J. Boland, B. Ridley,
  "Models of Diffuse Solar Fraction", in *Modeling Solar Radiation at the Earth's Surface*,
  Springer 2008, doi:10.1007/978-3-540-77455-6_8.
- **Reference implementation:** `pvlib.irradiance.boland` @ pvlib 0.16.1, all coefficients
  and guards passed explicitly.
- **Fixtures:** `boland-fixtures.json` (105 cases: erbs' edge set, the 1-hour coefficients,
  10 random coefficient pairs, 15 `dniExtra`), generated by
  `scripts/fixtures/decomposition-boland.py`. Also asserted: df = ½ at kt = b.
- **Tolerance:** `1e-9` (W/m²; kt dimensionless). Observed max error 6e-14 W/m²
  (`Math.exp` vs numpy, ~4e-15 relative).
