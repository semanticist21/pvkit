# faiman — Faiman module temperature

## Principle

`Tm = Ta + E / (U0 + U1·WS)` — module temperature rises with irradiance over a heat-loss
coefficient that grows linearly with wind. Same form as IEC 61853-2/-3. Defaults: `U0` 25
W/(m²·K), `U1` 6.84 W/(m²·K·m/s) (Faiman's fit), `windSpeed` 1. No guards; NaN/∞
propagate as in pvlib. (`faiman_rad`, the radiative-loss extension, is not implemented.)

## Reference

- **Spec:** D. Faiman, "Assessing the outdoor operating temperature of photovoltaic
  modules", *Progress in Photovoltaics* 16(4):307–315, 2008, doi:10.1002/pip.813.
- **Reference implementation:** `pvlib.temperature.faiman` @ pvlib 0.16.1, all arguments
  explicit.
- **Fixtures:** `faiman-fixtures.json` (107 cases: 7 edge conditions incl. 0 / −5 W/m²,
  calm, 30 m/s, −40/50 °C at default U; 100 random incl. random U0 10–40, U1 0–12),
  generated by `scripts/fixtures/temperature-faiman.py`.
- **Tolerance:** `1e-12` °C. Observed max error 0 (bit-identical on V8). Pure arithmetic in float64.
