# performance-ratio — IEC 61724-1 performance ratio (+ Dierauf temperature correction)

## Principle

- Final yield `Y_f = ΣE / P0` (kWh/kWp), reference yield `Y_r = ΣH / G_ref` (h, with
  `H` in kWh/m², `G_ref` in kW/m²). `PR = Y_f / Y_r`.
- Temperature-corrected (Dierauf et al. 2013, eq. for PR_corr):
  `PR_corr = ΣE_i / Σ[P0 · H_i/G_ref · (1 + γ (T_cell,i − T_ref))]`, with `γ` in 1/°C
  (Dierauf writes `1 − δ/100 (T_typ_avg − T_cell,i)` with δ in %/°C — identical).
- `T_ref` is a required input. Dierauf: `T_cell_typ_avg = Σ(G_i T_i) / ΣG_i` over a
  typical-year simulation (`irradianceWeightedTemperature`); IEC 61724-1 STC-corrected PR:
  25 °C. Using the test period's own weighted mean cancels the correction algebraically
  (PR_corr = PR), so it is never defaulted.

Series are per-interval values; energy and irradiation may also be one-element totals
(their lengths need not match). `tempCell` must align with `poaIrradiation`.
Weighting by irradiation `H_i` (not irradiance) keeps non-uniform intervals correct.
Guards: `pdc0Kw`, `irradRef` finite > 0 and the three correction inputs all-or-none, else
`RangeError`. Reference yield 0 (`ΣH = 0`) → NaN, also when `ΣE ≠ 0` (night tare would
otherwise give ±Infinity), e.g. a night-only window.

## Reference

- **Spec:** IEC 61724-1:2021, *Photovoltaic system performance — Part 1: Monitoring*, §§ on
  performance indices (yields, performance ratio); B. Marion et al., "Performance
  Parameters for Grid-Connected PV Systems", 31st IEEE PVSC, 2005, NREL/CP-520-37358,
  https://www.nrel.gov/docs/fy05osti/37358.pdf.
  T. Dierauf et al., "Weather-Corrected Performance Ratio", NREL/TP-5200-57991, 2013,
  https://www.nrel.gov/docs/fy13osti/57991.pdf.
- **Reference implementation:** none in pvlib 0.16.1; the fixture script evaluates the
  formulas above in numpy float64 with `math.fsum` sums.
- **Fixtures:** `performance-ratio-fixtures.json` (107 cases: hand check 0.8, G_ref ≠ 1000,
  zero energy, negative night tare, ΣH = 0 → NaN (with zero and with tare energy), 50 random uncorrected, 50 random
  corrected with T_ref = 25 °C or an independent 500-step weighted average), generated by
  `scripts/fixtures/metrics-performance.py`. Tests also assert the hand example and the
  cancellation identity.
- **Tolerance:** `1e-15` relative (absolute where the expected value is 0). Observed max
  error: 0 (bit-identical) — `compensatedSum` (Neumaier) returns the correctly rounded sum
  on these series, same as `math.fsum`, and the remaining ops are one or two IEEE
  divisions/multiplies. The margin (~4 ULP) absorbs a Neumaier vs exact-rounding difference
  on adversarial series.
