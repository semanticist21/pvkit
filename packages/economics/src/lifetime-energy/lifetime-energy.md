# lifetime-energy — annual yield with compound degradation

## Principle

`E_t = E_1 · (1 − d)^(t−1)`, `t = 1…years`; lifetime total `ΣE_t` (Neumaier sum). Degradation
compounds annually, as in NREL SAM's "Degradation" input (applied to the previous year's
output). Typical crystalline-Si `d` ≈ 0.5–0.8 %/yr (Jordan & Kurtz 2013). Year 1 is
undegraded. Guards: `firstYearEnergy` finite; `degradationRate` finite < 1; `years` whole ≥ 0.

## Reference

- **Spec:** D. C. Jordan, S. R. Kurtz, "Photovoltaic Degradation Rates — an Analytical
  Review", *Prog. Photovolt.* 21 (2013) 12–29, https://doi.org/10.1002/pip.1182;
  NREL SAM help, "Lifetime and Degradation", https://sam.nrel.gov/.
- **Reference implementation:** explicit formula, Python float64 `**` + `math.fsum`
  (arithmetic); NREL SAM via PySAM 7.1.1.post1 (`scripts/fixtures/economics-sam.py`) `Utilityrate5` lifetime
  degradation (convention: year 1 undegraded, compounding).
- **Fixtures:** `lifetime-energy-fixtures.json` (60 cases: hand check, d = 0, 0 years,
  gain, d = 0.5, 55 random up to 40 years), generated by `scripts/fixtures/economics.py`.
  `lifetime-energy-sam-fixtures.json` (6 cases, 1–40 years, d 0–2 %: SAM `annual_energy_value`
  with no load and buy = sell = 1/kWh). Test adds the geometric-series closed form.
- **Tolerance:** `1e-14` relative vs the formula (observed 0; margin covers 1–2 ULP `pow`
  differences across JS engines); `1e-12` vs SAM (observed 4.4e-14, SAM sums 8760 hourly
  values in a different order).
