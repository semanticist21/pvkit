# @pvkit/spec — agent notes

Package-only facts. Shared rules: `doc/conventions.md`, `doc/architecture.md`.

- One folder per library `src/<lib>/`: `index.ts`, `<lib>.ts` (record type + exported
  array), `<lib>.md` (`## Reference`), `<lib>.test.ts`, `<lib>-data.json`,
  `<lib>-fixtures.json`. Root `src/index.ts` exports types only.
- `<lib>-data.json` is a header + row table (`src/table.ts` expands it); never hand-edit — it
  is regenerated by `scripts/fixtures/spec-sam-libraries.py` from a pinned SAM release tag.
  `*-data.json` is excluded from biome (formatting would explode it ~20×).
- `tsdown.config.ts` loads `*-data.json` as `JSON.parse("…")`; rolldown's default JSON import
  emits a pretty object literal ~30 % larger and slower to parse.
- Data is as published (no curation); only renames and unit changes, both listed in the
  generator's mapping and mirrored by each test's `MAPPING`. `gammaPmp` is 1/°C (pvkit's unit);
  SAM `dT` → `tempDelta` (`deltaT` means TT − UT package-wide).
- Bumping the SAM tag: change `SAM_TAG`, run the script, update the README table (the only
  owner of row counts) and any quirk count a test pins.
- No ADR inverter coefficient DB yet: `pvkit-js/diode/inverter-adr` takes caller-supplied
  `adrCoefficients`. Also absent: spectral response data, datasheet parsing.
