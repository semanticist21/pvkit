# simplified-solis — simplified Solis clear-sky model

Clear-sky GHI, DNI and DHI from apparent elevation, aerosol optical depth at 700 nm,
precipitable water (cm) and pressure. Stated accuracy 15/20/18 W/m² (beam/global/diffuse).

## Principle

Radiative-transfer fit of the form `I = I0′ · exp(−τ / sin^k h)`, `h` apparent elevation,
`a = aod700`, `w` precipitable water, `lp = ln(p/p0)`, `p0 = 101 325 Pa`:

- `I0′ = I0 · (0.12·w^0.56·a² + 0.97·w^0.032·a + 1.08·w^0.0051 + 0.071·lp)`.
- Beam `DNI = I0′·exp(−τb / sin^b h)`, global `GHI = I0′·exp(−τg / sin^g h)·sin h`,
  diffuse `DHI = I0′·exp(−τd / sin^d h)`; `τb, b, τg, g, τd, d` are quadratic/quartic fits
  in `a`, `ln w`, `w`, `lp` (Ineichen 2008, eqs. 3–8; coefficients in the source).
- `τd` uses one coefficient set for `a < 0.05` and another for `a ≥ 0.05`.

Guards (pvlib behaviour): `w < 0.2` clamped to 0.2 cm; `sin h` floored at 1e−30 so the
sun below the horizon gives ≈0 rather than NaN. RangeError for `aod700 < 0` or
`pressure ≤ 0` (log of a non-positive ratio / outside the fit; pvlib returns garbage/NaN).

## Reference

- **Spec:** P. Ineichen, "A broadband simplified version of the Solis clear sky model",
  *Solar Energy* 82(8):758–762, 2008, doi:10.1016/j.solener.2008.02.009.
- **Reference implementation:** `pvlib.clearsky.simplified_solis` @ pvlib 0.16.1, all
  arguments explicit.
- **Fixtures:** `simplified-solis-fixtures.json` (146 cases: sun at zenith, aod700 0 / just
  below / at the 0.05 switch / 0.45, pw clamp 0–0.2, pressure 41 kPa, elevation 5° to −30°,
  100 random over the fitted ranges, 30 random elevation 0–5°), generated by
  `scripts/fixtures/clearsky-simplified-solis.py`. No numeric worked example in the paper.
- **Tolerance:** `1e-10` W/m² absolute. Observed max error vs pvlib on V8: 2.3e-13 W/m²
  (relative 7e-15). Same formulas in float64; margin covers cross-engine `Math.pow`/`exp`.
