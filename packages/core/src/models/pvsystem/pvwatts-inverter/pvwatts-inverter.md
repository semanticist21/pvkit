# pvwatts-inverter — PVWatts inverter

AC output from DC input with the PVWatts part-load efficiency curve and clipping.

## Principle

With `ζ = P_dc / P_dc0` (`P_dc0` = inverter DC input limit, not the array rating):

- `η = η_nom/η_ref · (−0.0162·ζ − 0.0059/ζ + 0.9858)`, `η_ref = 0.9637`;
- `P_ac = max(0, min(P_ac0, η·P_dc))`, `P_ac0 = η_nom · P_dc0`.

At `ζ = 1`, `η = η_nom`. Guards mirror pvlib: at `P_dc = 0` the `0.0059/ζ` term is taken
as 0 (output 0, no NaN); below `ζ ≈ 0.006` η turns negative and output is clamped to 0
(pvlib GH 541); negative `P_dc` → 0; NaN propagates. `pdc0 ≤ 0` or NaN throws
`RangeError`. Some printed versions of the manual drop the parentheses; pvlib's grouping
(used here) is the intended one.

## Reference

- **Spec:** A. P. Dobos, "PVWatts Version 5 Manual", NREL/TP-6A20-62641, 2014,
  doi:10.2172/1158421, https://www.nrel.gov/docs/fy14osti/62641.pdf (inverter model).
- **Reference implementation:** `pvlib.inverter.pvwatts` @ pvlib 0.16.1, `eta_inv_nom` and
  `eta_inv_ref` passed explicitly.
- **Fixtures:** `pvwatts-inverter-fixtures.json` (109 cases: `P_dc` = 0, negative, ζ below
  and at 0.006, nominal, clipping, 80 random ζ 0–1.3 with random η, 20 low-power ζ 0–0.02),
  generated by `scripts/fixtures/pvsystem-pvwatts.py`. Clipping level and `η(ζ=1) = η_nom`
  are also asserted.
- **Tolerance:** `1e-14` relative to `max(1, |P_ac|)`. Observed max error on V8: 0 (only
  `+ − × /`); margin for fused multiply-adds.
