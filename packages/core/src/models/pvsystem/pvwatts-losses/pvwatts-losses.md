# pvwatts-losses — PVWatts system losses

Combined system loss from the ten PVWatts loss categories, in percent.

## Principle

`L_total = 100 · (1 − Π_i (1 − L_i/100))` over soiling, shading, snow, mismatch, wiring,
connections, LID, nameplate rating, age, availability (multiplied in that order, as
pvlib). Defaults are pvlib's (2, 3, 0, 2, 2, 0.5, 1.5, 1, 0, 3 %) → 14.08 %, the PVWatts
V5 default. No validation, as pvlib: negative losses (gains) are allowed and values over
100 % give an out-of-range total.

## Reference

- **Spec:** A. P. Dobos, "PVWatts Version 5 Manual", NREL/TP-6A20-62641, 2014,
  doi:10.2172/1158421, https://www.nrel.gov/docs/fy14osti/62641.pdf (system losses).
- **Reference implementation:** `pvlib.pvsystem.pvwatts_losses` @ pvlib 0.16.1, every
  category passed explicitly.
- **Fixtures:** `pvwatts-losses-fixtures.json` (66 cases: defaults, all zero, one and all
  at 100 %, a negative loss, 60 random 0–30 %), generated by
  `scripts/fixtures/pvsystem-pvwatts.py`. The 14.08 % default is also asserted.
- **Tolerance:** `1e-14` percent. Observed max error on V8: 0 (only `− × /`); margin for
  fused multiply-adds.
