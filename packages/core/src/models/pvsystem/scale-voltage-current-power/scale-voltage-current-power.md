# scale-voltage-current-power — module → array scaling

Scales one module's operating point to an array of `seriesModules` × `parallelStrings`.

## Principle

Voltages (`vMp`, `vOc`) × `seriesModules`; currents (`iMp`, `iSc`) × `parallelStrings`;
`pMp × seriesModules × parallelStrings` (pvlib's multiply order). Ideal scaling — no
mismatch or wiring loss (use `pvwatts-losses`). pvlib's optional `i_x`/`i_xx` columns are
not carried.

## Reference

- **Spec:** series/parallel circuit rules, as in `pvlib.pvsystem.PVSystem.scale_voltage_current_power`
  (no paper beyond Kirchhoff's laws).
- **Reference implementation:** `pvlib.pvsystem.scale_voltage_current_power(voltage, current)`
  @ pvlib 0.16.1.
- **Fixtures:** `scale-voltage-current-power-fixtures.json` (64 cases: unit factors, a
  20 × 300 array, a zero point, zero factors, 60 random), generated by
  `scripts/fixtures/pvsystem-scale-voltage-current-power.py`.
- **Tolerance:** `1e-15` relative to `max(1, |x|)`. Observed max error: 0 (one or two
  correctly rounded multiplies).
