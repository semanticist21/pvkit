# pvwatts-dc — PVWatts V5 DC power

Array DC power from effective plane-of-array irradiance and cell temperature.

## Principle

`P_dc = G_eff/1000 · P_dc0 · (1 + γ_pdc · (T_cell − T_ref))` [W], with `T_ref = 25 °C`.
`G_eff` must already include angle-of-incidence losses (not soiling/spectral). Evaluated in
pvlib's operation order (`G·0.001·P_dc0·(…)`), so results are bit-identical on V8.

No clamping: zero irradiance → 0, negative irradiance → negative power, NaN propagates —
all as pvlib. `pdc0 < 0` or NaN throws `RangeError`.

Not implemented: Marion (2008) low-irradiance correction (pvlib `k`, `cap_adjustment`;
default off in pvlib).

## Reference

- **Spec:** A. P. Dobos, "PVWatts Version 5 Manual", NREL/TP-6A20-62641, 2014,
  doi:10.2172/1158421, https://www.nrel.gov/docs/fy14osti/62641.pdf (eq. for DC output).
- **Reference implementation:** `pvlib.pvsystem.pvwatts_dc(k=None, cap_adjustment=False)`
  @ pvlib 0.16.1, `temp_ref` passed explicitly.
- **Fixtures:** `pvwatts-dc-fixtures.json` (107 cases: STC, zero and negative irradiance,
  γ = 0, pdc0 = 0, extremes 1500 W/m² / 90 °C / −40 °C, 100 random), generated by
  `scripts/fixtures/pvsystem-pvwatts.py`. STC and a +10 °C derate are also asserted from
  the manual's equation.
- **Tolerance:** `1e-14` relative to `max(1, |P|)`. Observed max error on V8: 0 (only
  `+ − × /`, which IEEE 754 rounds identically on every engine); the margin is for
  compilers that fuse multiply-adds.
