# dirindex — Perez DIRINDEX model

## Principle

`DNI = dniClearsky · DIRINT(ghi) / DIRINT(ghiClearsky)`, both DIRINT runs sharing zenith,
time, pressure, dew point and flags; the clear-sky run uses the neighbours' `ghiClearsky`
for its ΔKt'. Negative results → 0. Like pvlib there is no further guard: NaN when either
DIRINT is NaN or both are 0 (night, 87° < zenith ≤ 90°), and +Infinity when only the
clear-sky DIRINT is 0 (e.g. clear-sky DISC DNI clipped to 0 near the horizon while the
measured one is not). Neighbour handling as in `dirint`.

## Reference

- **Spec:** R. Perez, P. Ineichen, K. Moore, M. Kmiecik, C. Chain, R. George, F. Vignola,
  "A new operational model for satellite-derived irradiances: description and validation",
  *Solar Energy* 73(5):307–317, 2002, doi:10.1016/S0038-092X(02)00122-6.
- **Reference implementation:** `pvlib.irradiance.dirindex` @ pvlib 0.16.1 on the same
  series as dirint (clear sky = `pvlib.clearsky.ineichen`, Linke turbidity 3).
- **Fixtures:** `dirindex-fixtures.json` (165 cases, same series/instants as dirint, incl.
  one +Infinity case stored as `"Infinity"`, NaN as `null`), generated by
  `scripts/fixtures/decomposition-dirint.py`.
- **Tolerance:** `1e-9` W/m². Observed max error 5.9e-12 W/m² (2e-14 relative).
