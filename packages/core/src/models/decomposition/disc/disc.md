# disc — Maxwell DISC model

## Principle

1. `I0` = Spencer extraterrestrial irradiance with solar constant 1370 W/m²; `kt` =
   clearness index clipped to [0, 1].
2. Air mass: Kasten (1966) `AM = 1 / (cos z + 0.15 (93.885 − z)^−1.253)` (NaN for z > 90°),
   × `pressure / 101325` unless `pressure` is `null`, then `min(AM, maxAirmass)` (12).
3. `ΔKn = a + b · exp(c · AM)` with cubic-in-kt `a, b, c` (separate fits for kt ≤ 0.6 and
   kt > 0.6); `Knc = 0.866 − 0.122 AM + 0.0121 AM² − 0.000653 AM³ + 1.4e-5 AM⁴`.
4. `DNI = (Knc − ΔKn) · I0`; zenith > `maxZenith` (87°), GHI < 0 or DNI < 0 → 0.

Below the horizon `airmass` is returned as NaN and `dni` as 0, like pvlib. `RangeError` on a
non-finite `timeMs`.

## Reference

- **Spec:** E. L. Maxwell, "A Quasi-Physical Model for Converting Hourly Global Horizontal to
  Direct Normal Insolation", SERI/TR-215-3087, Solar Energy Research Institute, 1987,
  https://www.nrel.gov/docs/legosti/old/3087.pdf.
- **Reference implementation:** `pvlib.irradiance.disc` @ pvlib 0.16.1, every argument
  passed explicitly (incl. `pressure=None` cases).
- **Fixtures:** `disc-fixtures.json` (105 cases: both kt branches, kt clipped, negative GHI,
  `null`/low pressure, air-mass clip on/off, zenith 84–95°, leap day, 31 Dec of a leap year;
  60 random, 20 zenith 80–92°, 10 random non-default guards), generated by
  `scripts/fixtures/decomposition-disc.py`. NaN stored as `null`.
- **Tolerance:** `1e-9` (W/m²; kt, airmass dimensionless). Observed max error 1.1e-13 W/m²
  (~3e-16 relative).
