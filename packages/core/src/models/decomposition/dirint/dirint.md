# dirint — Perez DIRINT model

## Principle

1. Run DISC (`disc`) → `DNI_disc`, `kt`, clipped air mass `AM`.
2. Zenith-independent clearness `kt' = kt / (1.031 exp(−1.4 / (0.9 + 9.4/AM)) + 0.1)`,
   clipped to [0, 1].
3. Stability index `ΔKt'` = mean of `|kt' − kt'(neighbour)|` over the given
   `previous`/`next` samples (each neighbour's kt' from its own GHI, zenith, time and
   pressure). NaN differences are skipped like pandas `mean`; with none left ΔKt' is NaN.
   `useDeltaKtPrime: false` → bin "unknown".
4. Precipitable water `w = exp(0.07 Td − 0.075)` from dew point `tempDew`; omitted/`null` →
   bin "unknown".
5. Bins — kt': [0, .24, .4, .56, .7, .8, 1]; zenith: [0, 25, 40, 55, 70, 80, ∞);
   ΔKt': [0, .015, .035, .07, .15, .3, 1]; w: [0, 1, 2, 3, ∞). Out-of-range or NaN → result NaN.
6. `DNI = DNI_disc · C[kt'][z][ΔKt'][w]`; table `dirint-coefficients.ts` extracted from pvlib.

Scalar design: the time series is replaced by explicit neighbour inputs; a series caller
passes `series[i − 1]` / `series[i + 1]` (omit at the edges). Behaviour mirrored from pvlib:
NaN for zenith > 90° (air mass undefined), 0 for 87° < zenith ≤ 90°, NaN when ΔKt' is used
but no neighbour has a finite kt'.

## Reference

- **Spec:** R. Perez, P. Ineichen, E. Maxwell, R. Seals, A. Zelenka, "Dynamic
  Global-to-Direct Irradiance Conversion Models", *ASHRAE Transactions* 98(1):354–369, 1992.
- **Reference implementation:** `pvlib.irradiance.dirint` @ pvlib 0.16.1 on whole pandas
  series (`min_cos_zenith=0.065`, `max_zenith=87`, pressure/`use_delta_kt_prime`/`temp_dew`
  per series).
- **Fixtures:** `dirint-fixtures.json` (165 cases from 7 synthetic series — Ineichen clear
  sky × random cloud factor + noise incl. negative GHI: Golden 48 h hourly with dew point at
  82 kPa incl. both edges; Seoul 15-min with `pressure: null`; Sydney hourly with ΔKt' off;
  Tromsø winter 10-min near-horizon; steady very-clear and steady overcast 5-min series
  so every kt' and ΔKt' bin carries a non-zero DNI case; a single-sample series), generated by
  `scripts/fixtures/decomposition-dirint.py`, which also writes the coefficient table. NaN
  stored as `null`.
- **Tolerance:** `1e-9` W/m². Observed max error 1.1e-12 W/m² (2e-14 relative); a bin edge
  crossing would show as an O(10–100 W/m²) jump, so any pass means identical binning.
