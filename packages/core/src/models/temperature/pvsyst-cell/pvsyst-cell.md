# pvsyst-cell — PVsyst heat-loss-factor cell temperature

## Principle

`Tc = Ta + α·E·(1 − ηm) / (Uc + Uv·WS)` — absorbed irradiance not converted to electricity,
over a constant plus wind-proportional heat-loss factor. Defaults (pvlib): `windSpeed` 1,
`uC` 29, `uV` 0, `moduleEfficiency` 0.1, `alphaAbsorption` 0.9. Presets
(`pvsyst-cell-parameters.ts`): freestanding 29/0, semi-integrated 20/0, insulated 15/0.
`windSpeed` must be measured at the height `uV` was fitted for. No guards; NaN/∞ propagate
as in pvlib.

## Reference

- **Spec:** PVsyst SA, "PVsyst 6 Help — Array thermal losses",
  https://www.pvsyst.com/help/thermal_loss.htm; model form after Faiman (2008),
  doi:10.1002/pip.813.
- **Reference implementation:** `pvlib.temperature.pvsyst_cell` @ pvlib 0.16.1, all
  arguments explicit; presets from `TEMPERATURE_MODEL_PARAMETERS["pvsyst"]`, extracted by
  the fixture script.
- **Fixtures:** `pvsyst-cell-fixtures.json` (117 cases: each preset × 5 edge conditions
  incl. 0 / −5 W/m², calm and 30 m/s, −40/50 °C; two wind-dependent `uV` cases; 100
  random), generated by `scripts/fixtures/temperature-pvsyst-cell.py`.
- **Tolerance:** `1e-12` °C. Observed max error 0 (bit-identical on V8). Pure arithmetic in float64; the
  margin covers rounding-order differences.
