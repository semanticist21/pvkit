# noct-sam — SAM NOCT cell temperature

## Principle

System Advisor Model NOCT model (Gilman et al. 2018, §10.6, eq. 10.37):

```
NOCT′ = NOCT + adj(mountStandoff)       adj: ≤0 → 0, <0.5 → 18, <1.5 → 11, <2.5 → 6,
                                              ≤3.5 → 2, >3.5 → 0  (inches; pvlib's edges)
v′    = 0.51·WS (arrayHeight 1) | 0.61·WS (arrayHeight 2)
τα′   = τα · Eeff / E               (Eeff defaults to E → ratio 1)
Tc    = Ta + E/800·(NOCT′ − 20)·(1 − η/τα′)·9.5/(5.7 + 3.8·v′)
```

`arrayHeight` other than 1 or 2 throws `RangeError` (pvlib raises `ValueError`). With
`effectiveIrradiance` given and `poaGlobal` 0 the ratio is 0/0 → NaN, or x/0 → ∞ (result
`tempAir`), exactly as pvlib's array path; without `effectiveIrradiance`, zero irradiance
gives `tempAir`. Defaults: `transmittanceAbsorptance` 0.9, `arrayHeight` 1,
`mountStandoff` 4 (ground mount, no adjustment).

## Reference

- **Spec:** P. Gilman et al., "SAM Photovoltaic Model Technical Reference Update",
  NREL/TP-6A20-67399, 2018, §10.6, https://www.nrel.gov/docs/fy18osti/67399.pdf.
- **Reference implementation:** `pvlib.temperature.noct_sam` @ pvlib 0.16.1, all
  arguments explicit (irradiance passed as numpy scalars so x/0 follows numpy semantics).
- **Fixtures:** `noct-sam-fixtures.json` (121 cases: NOCT conditions, 0 / −5 W/m²,
  calm/30 m/s, arrayHeight 2, effective irradiance incl. Eeff/0, every standoff interval
  edge −1…10 in, 100 random), generated by `scripts/fixtures/temperature-noct-sam.py`.
  Also asserts `Tc = NOCT` at NOCT conditions with η = 0 and 1 m/s at module height.
- **Tolerance:** `1e-12` °C. Observed max error 0 (bit-identical on V8). Pure arithmetic in float64.
