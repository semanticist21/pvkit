# generic-linear-model — parameter translation between linear temperature models

Pure functions for pvlib's `GenericLinearModel` `use_*` / `to_*` methods: convert Faiman,
PVsyst, SAM NOCT and SAPM-module parameters to the generic linear model and back. Every
`From` returns `{uConst, duWind, moduleEfficiency, absorptance}` (spreads into
`genericLinear`); every `To` returns an object that spreads into the target model function.
No class, no hidden state: module properties travel with each call.

## Principle

With net absorptance `n = α − η` (Driesse et al. 2022):

- Faiman: `u_const = U0·n`, `du_wind = U1·n`.
- PVsyst (heats with `α(1 − η)`): ratio `r = n / (α(1 − η))`; `u_const = Uc·r`,
  `du_wind = Uv·r`. Takes/returns `alphaAbsorption` as α.
- SAM NOCT (wind at module height; `0.51` scales to 10 m): `u_noct = 800·τα / (NOCT − 20)`,
  `u_const = 0.6·u_noct`, `du_wind = 0.4·0.51·u_noct`; back: `u_noct = u_const +
  du_wind/0.51`, `NOCT = 20 + 800·τα / u_noct`. Takes/returns `transmittanceAbsorptance`
  as α. The 60/40 split is fixed, so only `u_noct` round-trips.
- SAPM module: line through `U(WS) = 1/exp(a + b·WS)` at `windFitLow`, `windFitHigh`
  (defaults 1.4, 5.4 m/s), scaled by `n`; back: `b = −ln(U_high/U_low)/(WS_high − WS_low)`,
  `a = −(ln U_low + b·WS_low)`.

Guard: conversions that divide by or scale with `n` throw `RangeError` unless
`absorptance > moduleEfficiency` (pvlib silently returns ∞/negative coefficients).

## Reference

- **Spec:** A. Driesse et al., "PV Module Operating Temperature Model Equivalence and
  Parameter Translation", 2022 IEEE 49th Photovoltaic Specialists Conference (PVSC).
- **Reference implementation:** `pvlib.temperature.GenericLinearModel` `use_faiman`,
  `use_pvsyst`, `use_noct_sam`, `use_sapm`, `to_faiman`, `to_pvsyst`, `to_noct_sam`,
  `to_sapm` @ pvlib 0.16.1 (fit winds passed explicitly).
- **Fixtures:** `generic-linear-model-fixtures.json` (184 cases, each tagged with `fn`:
  the pvlib docstring example η 0.19, α 0.88, Faiman 16/8; the four SAPM presets; 32
  random modules × all four `to_*` plus one `use_*`, half with non-default fit winds),
  generated by `scripts/fixtures/temperature-generic-linear.py`. Also asserts the docstring
  values (11.04, 5.52 → PVsyst 11.4048, 5.7024) and round trips.
- **Tolerance:** `1e-12` relative (`|Δ| / max(1, |x|)`). Observed max ~7e-16 on V8. `exp`/`log`
  plus division in float64; the margin covers cross-engine ULP differences.
