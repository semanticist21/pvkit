# specific-yield — final yield (kWh/kWp)

## Principle

`Y_f = ΣE / P0`: delivered energy (kWh) per kWp of array STC power, i.e. equivalent hours
at nameplate. Series summed with `compensatedSum`; negative entries (night tare) are kept.
Guard: `pdc0Kw` finite > 0, else `RangeError`. Empty series → 0.

## Reference

- **Spec:** IEC 61724-1:2021, *Photovoltaic system performance — Part 1: Monitoring*, §§ on
  performance indices (yields, performance ratio); B. Marion et al., "Performance
  Parameters for Grid-Connected PV Systems", 31st IEEE PVSC, 2005, NREL/CP-520-37358,
  https://www.nrel.gov/docs/fy05osti/37358.pdf.
- **Reference implementation:** none in pvlib 0.16.1; `math.fsum(energy) / pdc0Kw`.
- **Fixtures:** `specific-yield-fixtures.json` (60 cases: hand check 200, empty, zeros,
  `[1e16, 1, -1e16]` cancellation, 56 random series up to 400 steps), generated by
  `scripts/fixtures/metrics-performance.py`.
- **Tolerance:** `1e-15` relative (absolute where the expected value is 0). Observed max
  error: 0 (bit-identical) — `compensatedSum` (Neumaier) returns the correctly rounded sum
  on these series, same as `math.fsum`, and the remaining ops are one or two IEEE
  divisions/multiplies. The margin (~4 ULP) absorbs a Neumaier vs exact-rounding difference
  on adversarial series.
