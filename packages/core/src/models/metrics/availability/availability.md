# availability — time-based availability

## Principle

`A = Σa_i / N`: available periods over total periods, with `a_i` = 1 (available), 0
(unavailable) or the available fraction of period `i`. Excluded periods (night, force
majeure, curtailment per contract) are dropped by the caller before the call — the
exclusion rules are contract/standard-specific (IEC TS 63019), out of scope here.
Guards: empty series or any `a_i` outside [0, 1] (incl. NaN) → `RangeError`.

## Reference

- **Spec:** IEC 61724-1:2021, *Photovoltaic system performance — Part 1: Monitoring*, §§ on
  performance indices (yields, performance ratio); B. Marion et al., "Performance
  Parameters for Grid-Connected PV Systems", 31st IEEE PVSC, 2005, NREL/CP-520-37358,
  https://www.nrel.gov/docs/fy05osti/37358.pdf.
- **Reference implementation:** none in pvlib 0.16.1; `math.fsum(a) / len(a)`.
- **Fixtures:** `availability-fixtures.json` (60 cases: hand check 0.75, all-up/all-down,
  fractional, a full hourly year with 3 outages, 54 random 0/1 or fractional series up to
  300 periods), generated by `scripts/fixtures/metrics-performance.py`.
- **Tolerance:** `1e-15` relative (absolute where the expected value is 0). Observed max
  error: 0 (bit-identical) — `compensatedSum` (Neumaier) returns the correctly rounded sum
  on these series, same as `math.fsum`, and the remaining ops are one or two IEEE
  divisions/multiplies. The margin (~4 ULP) absorbs a Neumaier vs exact-rounding difference
  on adversarial series.
