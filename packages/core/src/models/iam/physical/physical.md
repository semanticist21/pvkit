# physical — Fresnel + absorption IAM

Transmittance of a glass cover (optionally AR-coated) relative to normal incidence.

## Principle

1. `cos θ1 = max(0, cos aoi)`, `sin θ1 = √(1 − cos² θ1)`; light from behind the plane gets
   `cos θ1 = 0` (grazing → total reflection).
2. Snell at each interface: `sin θ2 = (n1/n2)·sin θ1`, `sin θ3 = (n2/n3)·sin θ2`, with
   `n1 = 1` (air), `n2 = nAr` (coating) or `n`, `n3 = n` (glass).
3. Fresnel reflectance `ρs = ((n1 cos θ1 − n2 cos θ2)/(n1 cos θ1 + n2 cos θ2))²`,
   `ρp = ((n1 cos θ2 − n2 cos θ1)/(n1 cos θ2 + n2 cos θ1))²`, `ρ0 = ((n1 − n2)/(n1 + n2))²`;
   `τ = 1 − ρ`.
4. AR coating: `τ ← τ·(1 − ρ23)/(1 − ρ23·ρ12)` (geometric series of internal reflections).
5. Absorption: `τs,p ← τs,p·exp(−K·L / cos θglass)`, `τ0 ← τ0·exp(−K·L)`.
6. `IAM = (τs + τp)/2 / τ0`.

Refraction uses `θr = asin(sin(aoi)/n)` — pvlib notes De Soto Eq. 14 (`asin(n·sin aoi)`)
is a typo. `nAr` ≈ 1 counts as uncoated; `nAr` ≈ `n` skips the second interface
(numpy `isclose`: `|a − b| ≤ 1e-8 + 1e-5·|b|`).

Guards (pvlib behaviour): aoi ≥ 90 → 0 by the Fresnel terms when `n2 > 1`; when `n2 = 1`
the terms are 0/0, and pvlib forces only `aoi ≥ 90` to 0, so `aoi ≤ −90` with `n = 1`
stays NaN. NaN aoi → NaN. Parameters are not range-checked (pvlib does not).

## Reference

- **Spec:** W. De Soto, S. Klein, W. Beckman, "Improvement and validation of a model for
  photovoltaic array performance", *Solar Energy* 80(1):78–88, 2006,
  doi:10.1016/j.solener.2005.06.010; J. Duffie, W. Beckman, *Solar Engineering of Thermal
  Processes*, 3rd ed., 2006, §5.1–5.3.
- **Reference implementation:** `pvlib.iam.physical(aoi, n, K, L, n_ar=...)` @ pvlib 0.16.1.
- **Fixtures:** `physical-fixtures.json` (102 cases: aoi sweep −120…180 incl. 89.9/90/90.001,
  AR 1.29, `nAr` ≈ 1 and ≈ n, `n = 1`, `K = 0`, thick glass, 60 random), generated by
  `scripts/fixtures/iam-physical.py`.
- **Tolerance:** `1e-12`. Observed max error vs pvlib on V8: 3.3e-16 — same closed form in
  float64; the margin absorbs 1–2 ULP `Math.*` differences across engines.
