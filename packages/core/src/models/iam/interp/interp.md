# interp — IAM from a reference table (linear)

## Principle

Piecewise-linear interpolation of `(thetaRef, iamRef)` at `|aoi|`; beyond the table the end
segments are extrapolated (pvlib's `make_interp_spline(k=1)` extrapolates), and the result is
clamped to `≥ 0`. With `normalize` (default), divided by the **unclamped** interpolant at 0°
so IAM(0) = 1 even when the table does not start at 0.

Only `method='linear'` is implemented; pvlib's `'quadratic'`/`'cubic'` (scipy B-splines)
and its deprecated `interp1d` kinds are not.

Validation (`RangeError`): fewer than 2 points, length mismatch, `thetaRef` not strictly
increasing (scipy raises too), negative or NaN `iamRef` (pvlib rejects negatives only). NaN
aoi → NaN.

## Reference

- **Spec:** linear interpolation of measured IAM (e.g. IEC 61853-2 incidence-angle tables);
  no model-specific paper.
- **Reference implementation:** `pvlib.iam.interp(aoi, theta_ref, iam_ref, method='linear',
  normalize=...)` @ pvlib 0.16.1.
- **Fixtures:** `interp-fixtures.json` (96 cases: a 14-point 0–90° table, a 5–80° table with
  extrapolated normalisation and negative clamp, a 2-point table, 50 random tables; aoi
  −100…120, normalize on/off), generated by `scripts/fixtures/iam-interp.py`.
- **Tolerance:** `1e-12`. Observed max error vs pvlib on V8: 2.2e-16 (scipy's de Boor
  evaluation vs the two-point formula differ only in rounding).
