# combine-loss-factors — compound loss fractions

## Principle

Independent derates multiply: `L_total = 1 − Π (1 − Lᵢ)`. Empty input → 0. No range check:
a negative fraction is a gain, a fraction above 1 yields a nonsensical but visible result,
as in pvlib.

Scalar semantics: pvlib's `index`/`fill_method` reindexing of each Series is a time-series
concern left to the caller — combine the loss values valid at one instant.

## Reference

- **Spec:** product of transmission factors (e.g. PVWatts losses, Dobos 2014, NREL/TP-6A20-62641,
  https://www.nrel.gov/docs/fy14osti/62641.pdf).
- **Reference implementation:** `pvlib.pvsystem.combine_loss_factors(index, *losses,
  fill_method="ffill")` @ pvlib 0.16.1, one-sample Series per loss.
- **Fixtures:** `combine-loss-factors-fixtures.json` — 61 cases (empty, 0, 1, total loss
  mixed with others, tiny, negative, near-1, ten equal, 50 random lists of 1–11 factors),
  generated by `scripts/fixtures/losses-combine-loss-factors.py`.
- **Tolerance:** `1e-15` absolute. Observed max error vs pvlib on V8: 0 (same operations in
  the same order).
