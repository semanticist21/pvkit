# irradiance — shared rules

- Geometry and units per `doc/conventions.md`: degrees in, azimuth from north clockwise,
  irradiance W/m². Sky-diffuse models take `solarZenith` — pass apparent zenith if that is
  what the irradiance data was measured against.
- Guards mirror pvlib exactly, including its NaN/±∞ outcomes for inconsistent inputs
  (e.g. `ghi = 0` with `dhi > 0`); nothing is silently clamped beyond what pvlib clamps.
- Transposition fixtures share one scenario set generated by
  `scripts/fixtures/irradiance-total-irradiance.py`: 16 edge scenarios (all-zero irradiance,
  dhi = 0, dni = 0, ghi = 0 with dhi > 0, negative dhi, zenith 85/87/89.9/90/92/100°, tilt
  0/90/180°, sun behind panel, high/low albedo) + 120 random (zenith 0–89°, every 10th tilt
  up to 180°) + 30 random near-horizon (zenith 85–95°) = 166 cases. Air mass is pvlib's
  Kasten–Young relative air mass (NaN above 90°). JSON cannot hold NaN/±∞, so the generator
  writes them as strings and tests decode with `Number()`.
- Tolerance `1e-12` relative to `max(1, |expected|)` W/m²: same closed forms in float64;
  the margin absorbs 1–2 ULP `Math.*` differences across engines.
